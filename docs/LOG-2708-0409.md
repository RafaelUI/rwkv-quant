**Правка.** Ориентация протащена в `convert()` параметром
`transposed={ключ: надо ли транспонировать}`, `T` стала per-key,
умолчание `None` = всё сырое, то есть прежнее поведение и единственный
вариант для `.pth`. Карта строится в `load_pretrained_rwkvq` из
`codec.is_transposed(manifest, key)`. Вариант «нормализовать в
`.rwkvq`-ветке двойным транспонированием» отвергнут: он оставляет в коде
два взаимно гасящих `.T`, то есть ровно ту конструкцию, которая эту
ошибку и породила.
